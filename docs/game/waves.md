# 波次与出怪

## 波次数量与属性表

共 **20** 波。第 `w` 波的敌人生理属性（数量、最大生命值、移动速度）随着波次递增，以实现“初期艰难、后期爽杀”的平衡曲线：

1. **敌人数 count(w)**：
   ```text
   count(w) = round(3 × 100^((w-1)/19))，w ∈ [1, 20]
   ```
2. **生命值 HP(w)**：
   - $w = 1$: $HP(1) = 15$ （玩家飞弹基础伤害 12，需打 2 下击杀，产生初期紧迫感）
   - $w \ge 2$: $HP(w) = \text{round}(15 \times 1.25^{w-1})$ （指数成长以契合玩家后期成倍暴涨的割草秒伤）
3. **移动速度 SPEED(w)**：
   ```text
   SPEED(w) = 65 + 2 × (w-1) 像素/秒
   ```
   （移速从 65 逐渐递增到 103，带来逼真的物理压迫感）

## 波次刷新规则（与升级解耦）

**每一波统一流程**，无第 1 波例外：

1. 按 [出怪节奏](#出怪节奏) 逐只生成该波 `count(w)` 个敌人。
2. **本波最后一只生成完毕**。
3. 等待 **`WAVE_GAP_MS`**（默认 **3000** ms）。
4. 若 `w < 20`，开始第 `w+1` 波；若 `w = 20`，触发 [胜利判定](../game/overview.md#胜负条件)。

**不要求清场**：上一波未击杀敌人保留在场上；波次推进不依赖击杀数、不依赖是否升级。

## 出怪节奏

v1：**非同时生成**；每波在固定总时长内**均匀**刷出。

### 常量

| 常量                     | 默认值 | 说明                               |
| ------------------------ | ------ | ---------------------------------- |
| `WAVE_SPAWN_DURATION_MS` | 5000   | 单波从第一只到最后一只的出怪总时长 |
| `WAVE_GAP_MS`            | 3000   | 本波出怪结束后到下一波开始的间隔   |

### 生成时刻

第 `w` 波共 `n = count(w)` 只，第 `i` 只（`i ∈ {1,…,n}`）在波开始后的时刻：

```text
t_spawn(i) = (i / n) × WAVE_SPAWN_DURATION_MS
```

即第 1 只在 `duration/n`，第 2 只在 `2×duration/n`，…，第 `n` 只在 `duration`。

### 示例：第 1 波

- `n = 3`，`WAVE_SPAWN_DURATION_MS = 5000`
- 生成时刻：约 **1667 ms**、**3333 ms**、**5000 ms**
- 5000 ms 后进入 `WAVE_GAP_MS`，约 8000 ms 开始第 2 波

### 示例：第 20 波

- `n = 300`，`duration = 5000` → 平均每 **16.7 ms** 一只（高密波；实现时注意性能与对象池）

## 与升级的关系

- 波次索引 `w` 只控制**刷怪节奏与数量**。
- 升级所需击杀配额由**当前玩家等级**对应波次决定，见 [progression.md](progression.md)。
- 玩家可在第 3 波刷怪时，因击杀仍在攒第 2 级的升级配额——两条线独立运行。
