# 闪电链（Chain Lightning）

闪电链是除了奥术飞弹外的第二个主动技能。解锁该技能后，炮塔会与奥术飞弹独立冷却，自动向射程内的敌人释放一道可弹跳的链式闪电，对其造成伤害并附加麻痹减速效果。

## 基础（v1.1）

| 属性     | 说明                                                                                                                       |
| -------- | -------------------------------------------------------------------------------------------------------------------------- |
| 类型     | 锁敌瞬发 / 链式弹跳                                                                                                        |
| 初始解锁 | 需在三选一升级中抽到并选取「解锁闪电链」后才开启自动释放                                                                   |
| 基础伤害 | `CHAIN_LIGHTNING_BASE_DAMAGE`（建议 10）                                                                                   |
| 基础弹跳 | `CHAIN_LIGHTNING_BASE_BOUNCES`（建议 3 次，包括首个目标）                                                                  |
| 索敌射程 | `PLAYER_ATTACK_RANGE`（同奥术飞弹）                                                                                        |
| 首个目标 | 优先选择射程内距离城墙最近的活怪（防守优先级高）                                                                           |
| 弹跳转向 | 每次弹跳在全场范围内寻找距离当前受击者最近的、且在本次传导中**未被击中过**的活怪，弹射不受距离限制                         |
| 麻痹效果 | 被击中的敌人移动速度降低 `CHAIN_LIGHTNING_BASE_SLOW`（建议 30%），持续 `CHAIN_LIGHTNING_BASE_SLOW_DURATION`（建议 1.5 秒） |
| 基础冷却 | `CHAIN_LIGHTNING_BASE_COOLDOWN_MS`（建议 3500ms）                                                                          |

## 强化词条字段说明

| 字段            | 含义                                     |
| --------------- | ---------------------------------------- |
| `id`            | 程序用标识                               |
| `name`          | 选牌显示名（中文）                       |
| `effect`        | 效果描述                                 |
| `maxRank`       | 本局最多选取次数                         |
| `prerequisites` | 须已拥有的词条 id 列表                   |
| `mutexGroup`    | 互斥组；同组只能拥有一种（不含自身叠层） |
| `stackRule`     | 多次选取时的叠加规则                     |

| --------------- | ---------- | ------- | -------------- | ---------- | ------------------------------------------------------------------------- |
| `unlock_chain`  | 解锁闪电链 | 1       | —              | —          | 解锁闪电链技能，初始弹跳 3 次，冷却 3.5 秒                                |
| `chain_damage`  | 电能过载   | 5       | `unlock_chain` | —          | 每级闪电链直击与弹跳伤害 +30%                                             |

## 机制交互说明

### 解锁与前置

- 玩家开局只有奥术飞弹，升级三选一中会有概率刷新出 `unlock_chain`（解锁闪电链）。
- 一旦选取了 `unlock_chain`，后续的闪电链强化词条（`chain_damage`, `chain_bounces`, `chain_slow`, `chain_fork`, `chain_explode`, `chain_surge`）才会加入三选一随机池中。

### 弹跳转向算法

1. 从源点（初始为玩家发射源）射向首个目标。
2. 命中后，标记首个目标为「已访问」。
3. 在全场范围内寻找符合条件的活怪：
   - 过滤掉「已访问」的怪。
   - 优先选择距离当前目标最近的活怪。
4. 若找到，从当前目标拉出一条闪电链 VFX 指向新目标，造成伤害与减速，标记新目标为「已访问」，并将其设为当前受击者，最大弹跳次数减 1。
5. 循环第 3、4 步，直至弹跳次数归零，或范围内无符合条件的目标。

### 分叉闪电 (`chain_fork`)

- 首个目标受击后，寻找距离它最近的 **2** 个未访问的怪，并同时分裂出 2 条链子。这两条链子拥有独立的已访问列表，各自向下弹跳，直至各自的剩余弹跳次数用尽。

### 雷击爆轰 (`chain_explode`)

- 无论是单链还是分叉链，只要它“寿终正寝”（即剩余弹跳次数为 0，或找不到下一个弹跳目标），就在最后的受击者中心点触发一次雷击爆炸，伤害半径为 `CHAIN_LIGHTNING_EXPLODE_RADIUS`，对范围内所有敌人（包含最后受击者本身，但防止被直击二次判定伤害，需合理处理伤害结算）造成闪电链伤害的 `80%`。

### 视觉表现（VFX）

- 绘制闪电折线效果（在受击者两点之间生成若干个随机抖动顶点的折线，亮蓝色/电紫色），在屏幕上绘制，停留 120ms 后淡出消散。
- 被麻痹减速的敌人身体周围呈现淡蓝色的微弱电流火花特效，减速结束后移除。
