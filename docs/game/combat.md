# 战斗系统

## 我方

| 属性   | v1 行为                                                                   |
| ------ | ------------------------------------------------------------------------- |
| 站位   | 屏幕下方固定，不可移动                                                    |
| 攻击   | 敌人进入**技能射程**后自动索敌并施放 [奥术飞弹](skills/arcane-missile.md) |
| 多技能 | v1 仅奥术飞弹；冷却 / 齐射 / 连发由强化修饰                               |

### 待定常量（实现时填入 `src/game/data/constants.ts`）

| 常量                         | 建议初值 | 说明                               |
| ---------------------------- | -------- | ---------------------------------- |
| `PLAYER_ATTACK_RANGE`        | 待调     | 世界单位；进入此距离内可开火       |
| `ARCANE_MISSILE_COOLDOWN_MS` | 800      | 基础射击间隔（连发在此基础上叠加） |

## 城墙

| 属性          | v1 行为                                                |
| ------------- | ------------------------------------------------------ | ---------- |
| `WALL_MAX_HP` | 100（可调）                                            | 归零即失败 |
| 受击          | 敌人进入 **城墙攻击距离** 后，按固定间隔对城墙造成伤害 |
| 修复          | v1 无                                                  |

### 城墙相关常量

| 常量                            | 建议初值 | 说明                   |
| ------------------------------- | -------- | ---------------------- |
| `WALL_ATTACK_RANGE`             | 待调     | 敌人与此距离内开始拆墙 |
| `ENEMY_WALL_DAMAGE`             | 5        | 每次 tick 对城墙伤害   |
| `ENEMY_WALL_ATTACK_INTERVAL_MS` | 1000     | 拆墙攻速               |

## 敌人（v1 单一种类）

| 属性   | v1 行为                                  |
| ------ | ---------------------------------------- |
| 生成   | 见 [waves.md](waves.md)                  |
| 移动   | 自上方刷怪点向下直线移动，目标为城墙方向 |
| 对我方 | 不主动攻击我方单位（仅攻击城墙）         |
| 生命   | 统一 `ENEMY_HP`（建议初值 10，可调）     |

### 敌人常量

| 常量            | 建议初值 | 说明                 |
| --------------- | -------- | -------------------- |
| `ENEMY_HP`      | 10       |                      |
| `ENEMY_SPEED`   | 待调     | 像素/秒或世界单位/秒 |
| `ENEMY_SPAWN_Y` | 待调     | 刷怪区 Y 坐标        |

## 弹道与命中（概要）

详细机制与强化叠加见 [arcane-missile.md](skills/arcane-missile.md)。

- 基础：单体弹道，命中**第一个**碰撞敌人造成伤害。
- **穿透** 与 **爆炸** 互斥，不可同时拥有。
- 伤害、范围、分裂等由强化 rank 叠加。

## 游戏状态

| 状态       | 说明                                                       |
| ---------- | ---------------------------------------------------------- |
| `Playing`  | 波次推进、战斗、升级选牌（选牌时暂停或半暂停，实现阶段定） |
| `GameOver` | 城墙毁                                                     |
| `Victory`  | 第 20 波出怪流程结束且城墙存活                             |

v1 无暂停菜单要求；选牌 UI 打开时建议 **暂停波次计时与刷怪**（实现细节见 [architecture.md](../dev/architecture.md)）。
